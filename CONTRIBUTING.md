# Contributing

We welcome contributions! Please follow these steps:

1. **Open an Issue** – describe the bug or feature.
2. **Fork the repository** and create a branch (`git checkout -b my-feature`).
3. **Commit** your changes with a clear message.
4. **Push** and open a Pull Request.

For security issues, open a private issue with the label `security`.

All contributions are licensed under the project’s license.
